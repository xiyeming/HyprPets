针对在 **Hyprland** 环境下使用 **Rust** 开发一款**像素风格、高自定义度、具备 AI Agent 工具集成**的桌面宠物，我们需要从 **Linux Wayland 底层架构**、**像素美术引擎**、**状态机与交互设计** 以及 **AI Agent 增强** 四个维度对需求进行重构与升级。

以下是优化后的**完整产品与工程需求文档（PRD / Technical Spec）**：

---

# 像素桌面宠物项目需求 specification (Rust + Hyprland)

## 1. 架构设计与技术栈配置

为了保障在 Hyprland 下的原生体验（如无边框透明、窗口置顶、置底、穿透、跨屏漫游），抛弃传统 Heavy GUI（如 Electron/Qt），采用 Rust 极简全栈路线：

* **GUI & 图形渲染**：`wgpu` / `pixengine` 或 `macroquad` / `egui` (通过 `egui-wgpu` 结合透明无边框窗口)。推荐 `winit` + `wgpu` 纯手绘像素管道，内存占用控制在 `< 15MB`。
* **Wayland Protocol**：`smithay-client-toolkit` (SCTK) + `gtk-layer-shell` / `wlr-layer-shell-unstable-v1`。
* 利用 `wlr-layer-shell` 设置 `Layer::Overlay` / `Layer::Top`，保障跨 Workspace 依然可见。


* **Hyprland 进程通信 (IPC)**：利用官方 `hyprland-rs` 监听Hyprland 事件（如当前窗口切换、工作区变更、全屏状态等）。
* **动画与状态机**：基于 Rust `petgraph` 或自定义 **FSM (有限状态机)** 编排像素动作。
* **AI & MCP 扩展**：`tokio` 异步运行时 + `async-openai` / `reqwest` + **MCP (Model Context Protocol)** 客户端集成。

---

## 2. 核心功能需求模块 (Core Modules)

### 2.1 像素渲染与自定义动作系统 (Pixel & Animation Engine)

1. **Sprite Sheet 动态切片与解析**：
* 支持标准的 Aseprite 导出格式 (`.json` + `.png`) 或标准网格 Sprite Sheet。
* **像素热重载 (Hot-Reloading)**：运行时监视配置目录，修改图片或 JSON 配置后自动刷新动作，无需重启程序。


2. **无限扩展的状态机结构**：
```toml
# config/actions.toml 自定义动作示例
[actions.sleep]
fps = 4
loop = true
frames = [[0, 0], [1, 0], [2, 0]]
sound = "snore.wav"
next_action_random = ["idle", "stretch"]

[actions.walk_left]
fps = 8
movement = [-2, 0] # 相对移动像素量

```


3. **自适像素对齐 (Pixel Crispness)**：
* 启用近邻采样 (Nearest-Neighbor Filter)，避免缩放模糊；支持像素放缩倍率（1x, 2x, 4x 等）。



---

### 2.2 自由宠物换肤与自定义宠物 (Skin & Character Customization)

1. **模组化目录结构 (Moddable Workspace)**：
* 每个宠物为独立的文件夹结构：
```text
~/.config/hyprpet/characters/
├── cat_pixel/
│   ├── meta.toml      # 宠物名称、作者、默认缩放
│   ├── sprites.png    # 贴图
│   └── actions.toml    # 动作定义与音效映射
└── slime_pixel/

```




2. **右键动态菜单换肤**：
* 右键宠物唤出原生轻量微型菜单（轻量级透明像素风），扫描本地 `characters/` 目录，一键无缝无闪烁切换宠物模型。



---

### 2.3 物理交互、鼠标感知与自主漫游 (Behavior & Interaction)

1. **Hyprland 空间感知与物理漫游**：
* **窗口/工作区爬行**：通过 `hyprland-rs` 获取当前工作区窗口边界，宠物可以踩在活动窗口顶部（Window Titlebar）、屏幕底部，或在不同 Monitor 之间漫游。
* **全屏避让**：当检测到当前窗口进入 `fullscreen` 时，宠物自动透明化或隐匿至边缘。


2. **鼠标互动 (Mouse Interaction)**：
* **抓取与抛掷 (Drag & Drop)**：按住鼠标左键抓起宠物（触发 `grabbed` 动作），释放鼠标后受到重力物理作用落地（触发 `landing` 动作）。
* **触摸/抚摸**：鼠标移入 (Hover) 或连续点击，触发开心/摇尾巴动作，并播放轻量通知音效。
* **穿透模式切换 (Click-Through Option)**：快捷键或菜单开启 `Input Region` 穿透，避免阻碍工作操作。



---

### 2.4 通知音效与系统集成 (Audio & System Integration)

1. **极轻量音效引擎**：
* 基于 `rodio` 实现无阻塞音频播放（支持 `.wav`, `.ogg`）。
* 支持**动作音效**（如步频声、呼噜声）与**系统事件音效**。


2. **Linux 系统通知联动**：
* 监听 `DBus` 系统通知，当有新 Telegram/Discord/Email 消息时，宠物头顶弹出像素气泡，并播放专属提醒动作。



---

### 2.5 AI Agent & 工具集成 (Agentic Companion)

1. **MCP (Model Context Protocol) 插件对接**：
* 作为 Agent GUI 终端，集成轻量化 AI agent。
* **状态感知**：宠物能感知系统状态（如 CPU/内存过高时宠物表现出“擦汗/疲惫”，编译成功表现出“庆祝”）。


2. **CLI / MCP 工具感知（AI 编码陪伴）**：
* 当后台检测到 `Claude Code`, `Cursor`, `Terminal` 在长时间运行密集任务时，宠物进入“陪读/打字”状态。


3. **对话框与 AI 工具调用 (Tools Calling)**：
* 双击宠物唤出**像素输入框**：支持对话、调用本地 Shell 命令或 AI 工具（如查询天气、总结剪贴板内容、设置定时器）。



---

## 3. 完整需求矩阵总结 (Summary Specification)

| 模块 | 功能项 | 详细描述 | 优先级 |
| --- | --- | --- | --- |
| **渲染** | Wayland Layer-Shell Overlay | 极低内存占用 (<15MB)，支持多屏，图层置顶与透明度 | P0 |
| **渲染** | 像素渲染管道 | Nearest Filter 近邻采样，动态倍率缩放（1x-8x），无模糊 | P0 |
| **动作** | Sprite + JSON 编排 | 支持自定义帧率、循环、相对位移、音效触发 | P0 |
| **状态** | 自主状态机 (FSM) | 随机 Idle 动作、发呆、睡觉、踱步、攀爬窗口 | P1 |
| **交互** | 鼠标抓取 & 落地物理 | 拖拽响应、重力下落、点击反应、菜单呼出 | P0 |
| **换肤** | 模块化 Skin Directory | 右键菜单无缝热切换宠物皮肤，热重载配置文件 | P1 |
| **感知** | Hyprland IPC 整合 | 监听全屏避让、活动窗口位置附着、工作区切换感知 | P1 |
| **Agent** | AI & 工具交互 | 像素气泡对话、工具调用（剪贴板/定时器）、系统状态联动 | P2 |

## 4. 后续开发流程建议

1. **Phase 1 (底层打通)**：使用 Rust搭建 `winit` + `wgpu` 透明窗口，实现 `wlr-layer-shell` 协议在 Hyprland 下的稳定渲染。
2. **Phase 2 (像素引擎与交互)**：编写解析 `.toml` / `.json` 的 Sprite Sheet 解析器，接入状态机与鼠标抓取物理。
3. **Phase 3 (Hyprland IPC & 音效)**：通过 `hyprland-rs` 获取窗口坐标，接入 `rodio` 播放交互音效。
4. **Phase 4 (AI/MCP 接入)**：实现像素气泡对话框及基于 `tokio` 的 Agent 后台，让宠物具备工具调用能力。
